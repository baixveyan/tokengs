# 报告 02：自由空间统计几何正则（`SW + Packing + Inter`）实验（Exp-05 ~ Exp-07）

---

## 动机

在 `[Exp-01]` ~ `[Exp-04]` 的诊断中，每个 Token 解码出的 64 个子 Gaussian 在完整输出下表现出极大的中心方差（140 场景平均 `packing_ratio` 达 `642 ~ 717`，远高于紧凑目标 `~5.9`），且不同 Token 的中心高度混叠（`inter_distance` 仅 `0.50 ~ 0.56`）。

前人方案尝试在微调内循环中直接加入基于槽位统计分布的三项几何正则（Sliced Wasserstein 单峰分布损失 `SW` + 槽内紧凑密铺损失 `Packing` + 槽间马氏距离排斥损失 `Inter`），期望在不借助外部三维先验的情况下收紧每个 Token 的子高斯分布并拉开相邻 Token。本阶段旨在系统检验这套统计几何损失在三种微调载体上的真实效果与底层机制。

---

## 设计

在 `[Exp-02]`（`scene 微调`）、`[Exp-03]`（`token 微调`）、`[Exp-04]`（`scene + token 联合微调`）的内循环中，统一加入权重为 `λ_sw = 0.1, λ_packing = 0.001, λ_inter = 0.01` 的统计几何损失：
$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{render}} + 0.1\,\mathcal{L}_{\text{sw}} + 0.001\,\mathcal{L}_{\text{packing}} + 0.01\,\mathcal{L}_{\text{inter}}$$

对比以下 3 组实验：
- **`[Exp-05]` `scene_lr1e-2_geo_tuning`**：`scene 微调` + 统计几何损失（对照 `[Exp-02]`）；
- **`[Exp-06]` `token_lr1e-4_geo_tuning`**：`token 微调` + 统计几何损失（对照 `[Exp-03]`）；
- **`[Exp-07]` `scene_lr1e-2_token_lr1e-4_geo_tuning`**：`scene + token 联合微调` + 统计几何损失（对照 `[Exp-04]`）。

## 核心结论与下一步突破方向

1. **旧版统计几何约束在全部三种微调载体下均显著损害重建画质（PSNR 下降 `0.20 ~ 0.67 dB`）**，且导致视锥外高不透明漂浮物暴增近 6 倍（从 708 个增至 4,007 个）。
2. **定位了导致旧几何损失失效的三个核心机制原因**：
   - **`< 1/255` 死点污染**：渲染器实际已剔除 `opacity < 1/255` 的死点（占总数 30.1%），但旧几何损失未过滤死点；仅过滤死点后，`no_tuning` 的 `packing_ratio` 即从 `366.96` 降至 `5.30`（死点贡献了 59.5% 的虚假方差）；
   - **锁死线性头 `deconv` 的位置共线性**：同一个 Token 内外围机动子球与 34 个核心子球的 3D 位置权重 97.1% 共线，强拉外围子球坐标会把原本位于物体表面的核心子球一并拽离表面；
   - **`gsplat` 视锥外零梯度漏洞**：`Inter` 损失把高斯推向视锥外，而 `gsplat` 对被剔除的视锥外高斯不写 `means2d` 且反传梯度恒为 0，导致视锥外漂浮物失控。
