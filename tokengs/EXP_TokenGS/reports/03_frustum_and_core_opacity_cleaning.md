# 报告 03：解析视锥投影与 Token 离核 Opacity 门控清理实验（Exp-08 ~ Exp-10）

---

## 动机

在阶段 02 中我们发现：由于最后一层线性解码头 `deconv`（`Linear(1024 -> 896)`）被冻结，同一个 Token 内外围子球与 34 个核心子球的 3D 位置权重高度共线（97.1% 重合），任何强行拉拽外围离群点 `xyz` 坐标的约束都会连带把核心子球拽离表面；但与此同时，SVD 子空间分析证明外围子球的 **Opacity 权重有 97.7% 落在核心位置的 922 维正交零空间内**。

此外，官方 `visibility_loss` 直接使用 `gsplat` 输出的 `means2d`，对飞出全部 6 个输入视锥的漂浮物梯度恒为 0。因此，我们希望用纯 PyTorch 解析针孔投影修复视锥外监管漏洞，对比“拉 `xyz`”与“压 `opacity`”，并进一步对每个 Token 内部偏离核心的“半逃逸离群点”进行内循环 Opacity 门控清理，以实现 **① Token 更集中、② 单 Token 恢复连续、③ 消除视锥外 Floater、④ 减少有效 GS 数量（场景轻量化）** 四大目标。

---

## 设计

本实验基于 `scene_lr1e-2_token_lr1e-4` 联合微调（50 步），对比递进的三种方案：

- **`[Exp-08]` `scene_lr1e-2_token_lr1e-4_vis_xyz_tuning`（解析视锥投影拉 `xyz`）**：
  用 8 行针孔相机解析投影替代坏掉的 `gsplat` `means2d`，对落在全部 6 个输入视锥外的存活高斯（`opacity >= 1/255`）的 `xyz` 坐标施加拉力（权重 `1.0`）。
- **`[Exp-09]` `scene_lr1e-2_token_lr1e-4_vis_opac_tuning`（解析视锥投影压 `opacity`）**：
  使用相同的解析投影定位全部 6 个输入视锥外的存活高斯，但将越界坐标 `detach`（绝不拉拽 `xyz`），直接对其 `opacity` 施加线性下压惩罚（权重 `2.0`），将其压入 `< 1/255` 剔除区。
- **`[Exp-10]` `scene_lr1e-2_token_lr1e-4_vis_opac_core_gate2.5_tuning`（解析视锥压 `opacity` + 离核 `>2.5r` 空间门控清理）**：
  在 `[Exp-09]` 基础上，于 50 步内循环每一步及最终解码时，以每个 Token 内 Top-24 高不透明子球的坐标中位数为稳健核心 $\boldsymbol{\mu}_{s,\text{core}}$、中位离核半径为自适应核心半径 $r_{s,\text{core}}$（均 `no_grad`），对超出 $2.5\,r_{s,\text{core}}$ 的离核子球乘以平滑空间衰减门控：
  $$\alpha_{s,c} \leftarrow \alpha_{s,c} \cdot \exp\left(-2.0 \cdot \text{ReLU}\left(\frac{\|\mathbf{x}_{s,c}.\text{detach}() - \boldsymbol{\mu}_{s,\text{core}}\|_2}{r_{s,\text{core}}} - 2.5\right)^2\right)$$

## 核心结论与下一步突破方向

1. **对视锥外与离群点“压 Opacity”显著优于“拉 `xyz`”**：`[Exp-09]` 将视锥外高不透明漂浮物从 708 个压至 16 个（比 `[Exp-08]` 的 101 个干净 6 倍），且在 Demo 上取得最高 PSNR（`25.973 dB`）。
2. **内循环离核空间门控（`[Exp-10]`）在不明显损失 PSNR（140 场景 `27.422 dB`，仍高于 `scene_tuning` 的 `27.400 dB`）的前提下，彻底解决了单 Token 内部发散与断裂**：140 场景 `SW` 从 `0.710` 暴降至 `0.101`、`packing_ratio` 从 `717.26` 暴降至 `3.14`、单 Token 多孤岛率从 `26.5%` 降至 `1.5%`，每场景净减 6,287 个离核活点（连同 `<1/255` 死点共精简 30.85% 基元；若事后删去 `<0.01` 点可精简 39.8% 基元且 PSNR 仅差 `0.016 dB`）。
3. **局限性**：仅清理离群点的 Opacity 并不能告诉核心高斯“真实三维表面在什么深度”（`Warp-PSNR` 仍停留在 `20.04 dB`，`RayThick` 仍为 `0.254m`）。
