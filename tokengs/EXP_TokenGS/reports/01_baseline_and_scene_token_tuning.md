# 报告 01：前馈基线与 `scene` / `token` 微调对比实验（Exp-01 ~ Exp-04）

---

## 动机

TokenGS 官方论文正文将测试时微调描述为对解码器查询向量 `gs_tokens`（`[1, 4096, 1024]`）以学习率 `1e-4` 进行 50 步梯度更新（`token 微调`），而官方发布代码 `release 2026.6` 默认执行的是对编码器瓶颈输出 `scene_latents`（`[1, 4096, 1024]`）以学习率 `1e-2` 进行 50 步梯度更新（`scene 微调`）。

在解码器结构中，`scene_latents` 通过 Cross-Attention 向所有 Token 提供全局多视角场景特征（经 `LayerNorm`、Softmax 与 `LayerScale` 缓冲），而 `gs_tokens` 通过无归一化的残差直连通道逐行对应单个 Token 的局部解码输入（若使用 `1e-2` 学习率会令指数位置激活 $\exp(|u|)-1$ 在数步内溢出发散，必须使用 `1e-4`）。因此，我们需要明确区分并定量对比 **不微调**、**`scene 微调`**、**`token 微调`** 以及 **`scene + token 联合微调`** 的真实表现，确立后续几何优化的基准线。

---

## 设计

本实验基于官方 `dl3dv_latent_6v_ssim.safetensors` 权重，在冻结全部网络参数的前提下，仅使用 6 个输入视角的图像重建损失（$\mathcal{L}_{\text{render}} = 0.8\,\mathcal{L}_{\text{L1}} + 0.2\,\mathcal{L}_{\text{SSIM}} + \mathcal{L}_{\text{vis}}$）进行 50 步 Adam 优化，对比以下 4 种设定：

- **`[Exp-01]` `no_tuning`**：纯前馈推理，不做任何测试时微调；
- **`[Exp-02]` `scene_lr1e-2_tuning`**：只微调 `scene_latents`（`lr = 1e-2`），冻结 `gs_tokens`；
- **`[Exp-03]` `token_lr1e-4_tuning`**：只微调 `gs_tokens`（`lr = 1e-4`），冻结 `scene_latents`；
- **`[Exp-04]` `scene_lr1e-2_token_lr1e-4_tuning`**：同时微调 `scene_latents`（`lr = 1e-2`）与 `gs_tokens`（`lr = 1e-4`）。

## 核心结论与下一步突破方向

1. **`scene + token 联合微调`（`[Exp-04]`）在图像指标上取得全面最优（140 场景 All PSNR `27.481`）**：单调 `token`（`[Exp-03]`）缺乏全局特征更新，高频能量比 `HF ratio` 仅 `0.767`（画面偏糊）；联合微调兼顾了 `scene` 的全局清晰度与 `token` 的逐槽位独立修正能力（140 场景以 127 胜 / 13 负超越单调 `scene`）。
2. **暴露纯图像微调的几何缺陷**：纯图像 RGB 微调虽然将输入视角 `d0` 提升了 `+5.17 dB`，但跨视角深度不一致（`MV-Cycle`）反而从 `0.70%` 恶化至 `0.95%`（Demo 从 `1.66%` 恶化至 `2.12%`），视线深度厚度 `RayThick` 仍厚达 `0.364m`，说明模型通过堆叠半透明高斯过拟合输入视角，并未真正修正三维表面几何。
