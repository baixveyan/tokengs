# 对照 C0：ScanNet++ 纯 RGB 光度后训练（`sft_rgb_only`）

状态：已完成，50/50 场景、400 个新视角（6 卡并行训练 30 Epochs，最优权重为 Epoch 28，SHA256：`2ce172afb2e9e58dd107a366d115a279d513bc4f9d446ca012fbe7077876f045`）。

## 一、动机

为了严格区分“ScanNet++ 室内多视角图像域适应”与“激光扫描几何信息带来的三维空间能力提升”，在完全相同的预训练初始化、解冻层范围和训练预算下，建立不使用任何点云或网格几何监督的纯 RGB 后训练对照基线 C0。

## 二、设计

- **初始化权重**：官方 `dl3dv_latent_6v_ssim.safetensors`（strict 加载，第 0 步与 `baseline_pretrained_6view` 逐位一致）。
- **解冻范围（阶段 ④ 尾部 + KV 桥接，共 65.10M 参数）**：
  - `enc_dec_backbone.latents`（`[4096, 1024]`）
  - `enc_dec_backbone.latent_blocks.8 ~ 11`（后 4 层交叉/自注意力块）
  - `enc_dec_backbone.latent_kv_proj` + `enc_dec_backbone.k_proj_norm`
  - 其余模块（12 层 ViT 编码器、前 8 层 `latent_blocks`、`gs_tokens`、解码器、末端 `deconv`）完全冻结。
- **训练配置**：Preset `sft_scannetpp_rgb_only`，853 个 ScanNet++ 训练场景（repeat=4），6 输入视角 + 4 目标视角（`use_input_supervision=True`），分辨率 `256×448`，30 Epochs，峰值学习率 `4e-5`（OneCycleLR，warmup 400 步），FP32（`mixed_precision="no"`），seed=42。
- **训练损失**：仅基础光度与可见性损失 `0.8 * L1 + 0.2 * SSIM + 1.0 * Visibility`，0 点云/深度/法线监督。
- **评估协议**：最优验证权重保存于 `../sft_rgb_only/model.safetensors`，在 50 个官方验证场景（400 个新视角）上以纯 RGB + 相机前馈评测 PSNR / SSIM / LPIPS 及 G1–G4 三维几何指标。

## 四、局限与结论

纯 RGB 光度后训练在 ScanNet++ 上使 2D 新视角 PSNR 提升 `+0.6842 dB`（50 场景中 47 胜 3 负），但三维几何指标几乎原地踏步（`F-score@3cm` 仅从 `0.3212` 微升至 `0.3230`，`F-score@5cm` 从 `0.4453` 微降至 `0.4446`，`Depth RMSE` 仍高达 `32.5 cm`）。这直接证明：**仅靠 2D 照片光度损失微调阶段 ④ 记忆格，只能改善室内色彩/光照域适应，无法自动消除阶段 ⑥.1 读出头的三维子球散乱。**
