# EXP_TokenGS 全部实验总表（140 场景）

由 `scripts/build_all_experiments_table.py` 从各实验目录的 `scene_metrics.jsonl` 生成，不要手改；新实验跑完后重新运行脚本即可更新。同一份数据另存为 `all_experiments_table.csv`，可用表格软件打开。

- 每行一个实验，每列一个指标；第一列就是实验文件夹名（`EXP_TokenGS/<实验>/`）；数值是 140 个场景的平均值（显存峰值取最大值）。
- 没跑完 140 个场景、因为 Gaussian 出现 NaN/Inf 而中止的实验，指标格写“发散”。
- ↑ 越大越好，↓ 越小越好，→1 越接近 1 越好（HF ratio：渲染图与真值图的高频能量之比）；几何和针状指标没有统一的好坏方向。
- Δ 列：同一批场景逐个相减后取平均，方括号是 95% 置信区间，后面是“更好/更差”的场景数。重跑同一配置的噪声约 ±0.004 dB。
- 所有实验：FP32、release latent 模型 `dl3dv_latent_6v_ssim`；微调的实验都调 50 步；“官方 / 复刻”循环在 CPU 上逐位一致，140 场景上两者相差 +0.0002 dB（见 `reports/scene_tuning_noise_floor.json`）。
- “参考”两行是官方 release 文档里的数字，不是我们跑的，只有全部帧 PSNR / SSIM / LPIPS。
- 单场景运行（`demo/`）不在表内。
