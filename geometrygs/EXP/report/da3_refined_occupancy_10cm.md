# DA3 深度 → 10 cm 网格：边缘过滤、多视角一致性与 SfM 尺度

## 结论

2026-11-07 完成。在 `da3_occupancy_10cm` 的基础上加入三种可部署的改进，都只用输入 RGB 和相机，不用激光。在 20 个 DA3 未见场景上：

- **SfM 修正尺度最有效。**输入视角 SfM 估出的尺度与激光尺度之比，偏差中位数 0.75%，最大 3.0%；DA3 自己对齐相机得到的尺度偏差中位数 1.75%，最大 8.6%。“边缘过滤 + SfM 尺度”的 IoU 为 0.429（原始 0.326，仅边缘过滤 0.360），已接近用激光修正尺度的 0.452。深度误差中位数从 4.7 cm 降到 2.8 cm，<10 cm 的像素从 81% 升到 89%。
- **多视角一致性检查没有带来提升。**按 AnchorSplat 的规则（至少 1 个其他视角匹配）会丢掉 19.5% 的像素，IoU 反而降到 0.369，因为 11.2% 的像素根本没有其他输入视角能看到，被一律去掉。只去掉“与其他视角冲突”的点（不要求匹配）时 IoU 为 0.433，与不做一致性检查的 0.429 基本相同。
- 剩余误报中约 31% 落在“被无激光射线穿过的格子”里（玻璃、窗户、扫描空洞），其中一部分可能是标签缺失而不是预测错误；排除这些格子后 IoU 为 0.479。

## 方法

与 `da3_occupancy_10cm` 相同的窗口、DA3 设置（位姿条件，518×896）和标签。一个格子内至少有 1 个保留的点即为占据。

| 改进 | 做法 |
|---|---|
| edge | 去掉 DA3 自身 5×5 邻域深度范围超过 10% 深度的像素（飞点，见 `da3_flying_pixels`） |
| mv1 / mv2 | 多视角一致性：把每个点投影到其余 5 个输入视角，与那里的 DA3 深度比较。差值 < 3 cm + 2% 深度为匹配；点比对方看到的表面更靠前、超出容差为违反（对方本应看到它）；更靠后视为遮挡，不计。保留至少 1 / 2 个匹配且至多 1 个违反的像素 |
| mvv | 只要求至多 1 个违反，不要求匹配；保留只有一个视角能看到的区域 |
| sfm_global / sfm_view | 输入视角 SfM（已知位姿，SIFT 8192，1024×1792，沿用锚点的可靠性筛选）。在每个可靠点被观测的像素处，取 SfM 深度 / DA3 深度的中位数，作为整个场景或每个视角的尺度（单视角观测少于 20 个时用整体尺度）。观测少于 50 个时退回相机尺度 |
| oracle | 每场景激光 / DA3 深度中位比，只作诊断 |

“远处误报”指离任何真实表面格超过 1 格的误报格。SfM 整体尺度 + edge 时，误报中 77% 只偏离真实表面 1 格。

逐场景 IoU 中位数：原始 0.378 → edge 0.423 → SfM + edge 0.457（范围 0.239–0.733）→ 再加 mvv 0.458。

尺度与深度（20 场景均值）：

| 尺度 | 与激光尺度之比偏差（中位 / 最大） | 深度误差中位数 | <10 cm |
|---|---|---:|---:|
| 相机（DA3 Umeyama） | 1.75% / 8.6% | 4.7 cm | 80.8% |
| SfM 整体 | 0.75% / 3.0% | 2.8 cm | 88.5% |
| SfM 逐视角 | — | 2.8 cm | 88.4% |
| 激光（诊断） | 0 | 2.5 cm | 90.3% |

之前尺度偏差最大的场景改善明显：`578511c8a9` 相机尺度偏 8.6%，SfM 尺度偏 1.3%；`5f99900f09` 从 6.8% 降到 1.8%；`9071e139d9` 从 6.4% 降到 0.8%。

多视角一致性的统计：11.2% 的像素没有任何其他输入视角能看到；2.3% 的像素被至少 2 个视角判为违反；经过 edge 过滤后的像素中，16.3% 不满足 mv1。也就是说，mv1 丢掉的主要是只有一个视角看到的正常区域，而不是错误的点。DA3 是 6 张图联合预测的，各视角之间本来就比较一致，整片表面的深度偏移往往在所有视角里一起出现，一致性检查也查不出来。

### 激光空洞的影响（敏感性分析）

`grid_occupancy_10cm` 标出了“被没有激光命中的输入射线穿过”的格子（玻璃、显示器、扫描边缘）。这些格子里即使有真实物体，标签也是 0。

| 变体 | 误报中位于这类格子的比例 | 排除这类格子后的 IoU |
|---|---:|---:|
| 相机尺度，全部像素 | 31.4% | 0.385 |
| SfM 整体尺度 + edge | 31.0% | 0.479 |

这只是上限式的敏感性分析：这类格子里也有真正的误报，因此主结果仍以全部格子为准。

## 下一步含义

1. “DA3 深度 + 边缘过滤 + 输入视角 SfM 尺度”可以作为三维 query 的几何初始化：完全可部署，深度误差中位数 2.8 cm，网格误报多为一格偏移。
2. 多视角一致性检查不适合直接沿用 AnchorSplat 的“至少一个视角匹配”规则：它会删掉只有一个视角看到的区域。
3. 剩下的误差主要是一格之内的偏移和标签缺失（玻璃等）；继续压低误差，需要比 10 cm 格子更细的评估，或者在 ScanNet++ 训练集上微调 DA3。
