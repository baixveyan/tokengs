# 网格统计与激活预测小实验

## 结论

2026-11-07 已完成网格统计和冻结上游的小型共享分类器实验。三维投影特征在独立验证场景上的表面/自由空间排序优于纯相机几何输入，但当前探针没有实现可靠的跨场景高召回关闭：校准集设定 99% 表面召回阈值后，图像探针在验证集上保留全部格子，已确认空域关闭率为 0%。

这支持继续研究三维观测读取，也暴露了门控泛化问题。不能据此宣称网格生成器已成功、可以删除 90% 的空间，或动态高斯预算已改善质量。本轮没有训练新的 GS 生成器，也没有改变当前主模型。

## 固定协议

| 项目 | 设置 |
|---|---|
| 训练 / 阈值校准 / 独立验证 | 16 / 4 / 8 个互不重叠场景 |
| 场景来源 | 训练与校准来自官方 train；独立验证来自官方 val 前 8 场景 |
| 训练场景选择 | seed=42，按场景 ID 的固定 SHA-256 排序选择 |
| 每场景 | 一个固定窗口，6 输入、8 不重叠目标，窗口 18 |
| 图像 | 256×448 |
| 空间 | 输入相机 mean-camera 坐标系，0.3 单位/米 |
| 网格范围 | 物理 x/y∈[-3,3] m，z∈[0,6] m；不依赖激光包围盒 |
| 分辨率 | 16³=4096 格，每格 37.5 cm |
| 数值精度 | FP32，关闭 TF32 |
| 上游 | 官方 DL3DV 6 输入 checkpoint，严格加载，全部冻结 |
| 图像特征 | 原 4096 维多尺度 patch 特征，固定随机投影至 64 维，投影 seed=173 |
| 查询 | 每格中心＋8 个内部角点；按三维坐标投影双线性取图像特征 |
| 融合 | 仅相机有效性掩码，聚合特征均值与跨视角方差；不使用深度可见性掩码 |
| 对照 | 28 维网格/相机信息 → 128 → 64 → 1，12,033 参数 |
| 图像探针 | 相机信息＋128 维聚合图像特征 → 128 → 64 → 1，28,417 参数 |
| 训练 | 每组 1000 更新；每卡 512，7 卡共 3584；表面/空域各半采样 |
| 优化器 | AdamW，lr=1e-3，weight_decay=1e-4，梯度裁剪 5 |
| 阈值 | 只在 4 个校准场景上按 95%/99% 表面召回设定；不按验证表现挑 checkpoint |

投影压缩只是低成本探针的特征输入选择，不是把主模型缩为 64 维。探针结果也不能代表所有可能的三维特征融合器的能力上限。

RGB/相机是探针的全部观测输入。SfM、激光深度、mesh distance、原模型高斯和目标图像均不输入分类器。激光用于标签和诊断；目标视角只检查表面覆盖，不参与特征提取、归一化、训练或阈值选择。归一化统计仅拟合训练场景的已标注格子。

## 标签与统计口径

- **表面**：输入激光深度反投影的有效表面点落入格子。
- **已确认空域**：至少两个输入视角的深度提供格子在表面之前的证据，且格子中心到激光 mesh 的距离大于其外接球半径＋1 cm。该条件保守排除包含 mesh 表面的体素。
- **未知**：其余格子，包括出视锥、遮挡后方、近表面但未确认、扫描缺失区域。训练损失不把这些格子当负例。
- 有效高斯：对官方高斯执行真实 input-view rasterization，通过对虚拟颜色求导得到每个高斯的总 `T*alpha` 合成权重。只计超过 `1e-6` 像素等价权重的高斯。不是按原始 opacity 筛选，也不把死槽位计为有效容量。
- 高斯按**中心**落格；其椭球支撑可跨格，不能把这一分箱等同于真实的区域渲染归属。
- 纹理量为输入图像灰度梯度的格内平均，几何变化量为法线二阶矩的方向离散度；都是诊断代理。

## 网格与容量结果

以下为 8 个独立验证场景的场景均值：

| 统计 | 结果 |
|---|---:|
| 观察到表面的格子 | 374.5 / 4096，9.14% |
| 已确认空域 | 122.25 / 4096，2.98% |
| 未知 | 3599.25 / 4096，87.87% |
| 输入激光有效命中落在固定体积内 | 92.49% |
| 官方有渲染贡献的高斯数 | 185,391 |
| 其中中心位于网格体积内 | 167,608 |
| 网格内高斯中心对应的总合成权重占比 | 90.79% |
| 每表面格的高斯数量均值 | 498.3 |
| 各场景每表面格高斯数量中位数的平均 | 190.5 |
| 各场景每表面格高斯数量 p90 的平均 | 1241.1 |
| 高斯数量 >64 的表面格比例 | 63.23% |
| 已确认空域内高斯中心对应的合成权重比例 | 3.71% |

**87.87% 未知不能解释为可删除空域。** 这个固定体积还包含视锥外区域；2.98% 也不是场景实际空体积的估计，只是当前输入和保守标签能确认的空格比例。范围之外仍有约 7.51% 输入表面命中，不能声称覆盖完整场景。

格间高斯分布非常不均匀，说明按格固定 64 未必合适。但官方 TokenGS 存在雾、重复和错层，因此这些数量不是最优预算真值，不能据此认定某格必须保留几百个高斯。

高纹理组平均 484.0 GS/格，其他纹理组 503.1，本轮没有观察到简单的“纹理越密，高斯越多”。法线变化较大的组为 686.3，较平的组为 334.3；可能反映局部多表面复杂度，也可能混入原模型的冗余。尚未验证动态预算的因果收益。

## 激活预测结果

指标在所有验证场景已标注格子上合并计算；未知格子不进入 AUC。

| 模型 | 训练 AUC | 校准 AUC | 独立验证 AUC | 独立验证 AP |
|---|---:|---:|---:|---:|
| 仅相机/网格信息 | 0.9743 | 0.6915 | 0.6590 | 0.8464 |
| 加三维投影图像特征 | 0.99997 | 0.5821 | 0.8964 | 0.9585 |

图像特征在这 8 个验证场景中提供了额外的区分信息，但校准场景上没有保持这个优势，训练集接近完美与校准集表现落差显示明显的泛化问题。固定 16 个训练窗口被大量重复采样，不代表充分的场景多样性。

按校准集设置阈值，独立验证结果如下：

| 校准目标 | 模型 | 实际表面召回 | 已确认空域关闭率 |
|---|---|---:|---:|
| 95% | 相机/网格 | 90.49% | 15.75% |
| 95% | 加图像特征 | 100% | 1.12% |
| 99% | 相机/网格 | 97.96% | 1.23% |
| 99% | 加图像特征 | 100% | **0%** |

图像模型的 99% 校准阈值降至约 `8.49e-23`，验证集所有格子都被保留。目标视角表面召回 100% 在这里也只是“全部开启”的结果，不是生成能力提升。目标覆盖指标只针对固定体积内的激光命中。

一个明确的失败案例是校准场景 `9471b8d485`：图像模型在整体 99% 校准阈值下，它自己的表面召回仍只有 95.34%。整体召回保证不等于逐场景保证。其余三个校准场景均保留表面、几乎不关格。

为区分“排序有信息”和“阈值能泛化”，补充了验证标签选择阈值的 **oracle 诊断**：在验证集自身 99% 表面召回附近，能关闭 23.21% 已确认空格；95% 时可关闭 50.51%。这使用了验证标签，**不能作为部署表现，也不能替换上表结果**，单独保存在 `test_oracle_thresholds.json`。

## 下一步含义

当前证据支持保留“网格分工＋三维读取”的研究方向，但还不支持直接上线硬关闭或按未知比例削减高斯。后续首先需要解决激活预测跨场景失稳：增加窗口多样性、限制过拟合、保留未知状态，并对稀疏 SfM/几何证据的增益单独验证。随后才用生成对照验证在同等表面覆盖和高斯预算下的收益。
