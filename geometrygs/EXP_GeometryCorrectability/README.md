# 验证：模型在“有证据”的地方，是否没有把几何改对？（2026-11-05）

## 预先登记（写于运行之前，结果出来后不修改）

**要检验的命题**：冻结的 RGB 路径里已经存在能纠正几何错误的多视角证据，但现有模型（TokenGS 的单次回归、LocusGS 的逐层锚点更新）没有利用它把几何改对。

三项实验分别检验命题的一部分。全部在 ScanNet++ 上进行，激光网格作真值；FP32，TF32 关闭；评测集为官方 50 个验证场景（6 张输入，窗口内 8 个目标）。

### 实验 1：同表面冲突

- **问题**：现有“厚度 / 跨 token 叠放”里，有多少是同一物理平面上的真实错误分歧，又有多少是共同偏差？
- **模型**：release 6v、⑫、LocusGS、论文版 TokenGS 4v。
- **像素集合**：目标视角中满足以下全部条件的像素：激光命中；渲染不透明度 > 0.5；以该像素为中心的 9×9 窗口全部有激光；窗口内各点到中心切平面的距离都小于 1 cm；法线与中心法线夹角都小于 10°。对照集合是其余激光像素。
- **分解**：把像素上的高斯中心深度换算成沿激光法线方向的偏差（乘以 |视线方向 · 法线|）。全变差公式保证：法向均方误差 = 共同偏差² + token 间分歧² + token 内分散²。
- **判定**：在平面内部像素上，
  - token 间分歧占法向均方误差 ≥ 30%，且分歧中位数 ≥ 1 cm，则判定“同表面冲突真实且显著”；
  - 占比 < 15%，则判定“主要是共同偏差，不是 token 之间的冲突”。

### 实验 2：LocusGS 中间锚点扰动后能否恢复

- **问题**：锚点被放错之后，后续层能否根据观测把它拉回来？
- **做法**：
  - 每个场景随机抽 15% 的存活 token，在第 3、7、12 层的输入处给锚点加一个已知扰动；
  - 扰动有三种：沿主视角视线 ±5% 深度、沿主视角视线 ±10% 深度、垂直于视线 10% 深度；
  - 对照组为不扰动的同一前向。
- **恢复率**：r = 1 − (最终位移在扰动方向上的投影) / 扰动长度。r = 1 表示完全恢复，r = 0 表示误差原样保留。分别对最终锚点和最终高斯中心（不透明度加权）计算。
- **判定**：第 7 层输入、沿视线 10% 的扰动，在看到 ≥2 个视角的 token 上，
  - 高斯中心恢复率中位数 < 0.5，判定“不能根据观测纠正”；
  - ≥ 0.8，判定“能恢复”。

### 实验 3：冻结特征能否在几个候选位置中挑出正确的那个

- **问题**：模型自己的冻结特征（以及原始 RGB）是否含有足以纠正其深度错误的多视角证据？
- **做法**：
  - 对目标视角的每个像素，以模型渲染深度 z 为中心，沿视线取 31 个候选深度 z·(1+o)，o 从 −0.3 到 0.3 等间隔（步长 2%）；
  - 把每个候选投影到 6 张输入图上采样特征，用一个小评分器挑出最受多视角特征支持的候选；
  - 评分器只能看到各视角特征的一致性（跨视角均值、方差、两两余弦相似度和有效视角数），看不到候选偏移量和深度本身，因此无法靠学习数据集偏置取胜。
- **训练与评测**：
  - 评分器只在 ScanNet++ 训练集的 160 个场景上训练，与验证场景不重叠；
  - 冻结特征先用 PCA 降到 256 维，PCA 基底只用 12 个训练场景拟合；
  - 在 50 个验证场景上评测。
- **几种评分方式**：
  - 冻结特征评分器：release 的多尺度编码器特征（⑫ 的编码器与 release 逐位相同），LocusGS 用它自己的编码器特征；
  - RGB 评分器：同样结构，输入换成原始 RGB 的 3×3 邻域；
  - 直接残差：同样的特征，但只在模型给出的位置采样，直接回归深度修正量；
  - 光度一致性：不训练，取各视角 3×3 归一化色块方差最小的候选；
  - 候选上限：离真值最近的候选，只作诊断参考。
- **证据可用性**：把激光真值点投影到输入视角，在不被遮挡（与输入视角激光深度相差 < 2%）的视角数，记为“可见视角数”。
- **判定**：在“模型误差 > 5%、可见视角数 ≥ 2、真值落在候选范围内”的像素上，
  - **H1 成立的条件**：冻结特征评分器使这些像素的平均相对误差降低 ≥ 30%，同时在模型误差 < 2% 的像素上，被评分器改坏到 > 5% 的比例 ≤ 10%；
  - **H1b**（候选证据读取优于直接回归）：在所有落在范围内的像素上，候选评分器的平均相对误差比直接残差低 ≥ 10%；
  - 真值超出 ±30% 范围的像素比例单独报告，不计入 H1。

### 总判定

- release / ⑫ 满足 H1，且 LocusGS 满足 H1 并在实验 2 中“不能纠正”，则命题成立，支持“证据驱动的几何纠错”路线。
- 如果评分器也挑不对（H1 不成立），说明问题在证据不足或特征丢失信息，转向不确定性表示或特征研究。
- 实验 1 只决定是否保留“跨 token 冲突”这一动机，与总判定独立。

### 已知局限（预先说明）

- 评分器在 ScanNet++ 训练集上训练，而 release 本身没有在 ScanNet++ 上训练过；所以加入 ⑫ 作对照，看经过激光监督微调的模型是否仍留下可纠正的错误。
- 候选只沿目标视线取，所以这里检验的是深度纠错，不检验横向错误。
- 冻结特征经过 PCA 降维，结论是“降维后的特征中至少有这么多证据”，是一个下界。

“冻结的 RGB 路径里已经有证据、只是模型没有用来纠错”这一命题**没有得到支持**。按预先登记的分支，“证据驱动的几何纠错”不应作为论文主线。

### 实验 1：同表面冲突（50 场景，约 1970 万个激光平面内部像素）

| 模型 | 共同偏差中位 | token 间分歧中位 / p90 | 法向均方误差构成（偏差 / 分歧 / token 内） | 分歧 > 2 cm 的像素占比 | 判定 |
|---|---:|---:|---|---:|---|
| release | 10.3 cm | 6.9 / 28.2 cm | 76% / 22% / 2% | 94% | 介于两档之间 |
| ⑫ | 2.7 cm | 3.0 / 7.6 cm | 71% / 17% / 12% | 72% | 介于两档之间 |
| LocusGS | 7.0 cm | **11.1 / 34.5 cm** | 58% / **39%** / 4% | 98% | **真实且显著** |
| 论文版 4v | 9.7 cm | 11.9 / 35.6 cm | 47% / 25% / 28% | 99% | 介于两档之间 |

- 在真实的单一平面上，所有模型都存在不同 token 沿法向前后错开的情况；这在 LocusGS 上最严重。
- 但对 release 和 ⑫ 来说，误差的大头是整体偏移（共同偏差），而不是 token 之间的冲突。
- 激光监督（⑫）把偏差和冲突都压到了最低。

### 实验 2：LocusGS 锚点扰动后能否恢复（50 场景，每种条件约 2.5 万个 token）

| 扰动位置 | 沿视线 ±10% 深度：高斯中心恢复率中位（看到 1 个视角 / ≥2 个视角） | 垂直视线 10%：恢复率中位（≥2 个视角） | PSNR（基线 29.52） |
|---|---|---|---:|
| 第 3 层输入 | 0.92 / 0.96 | 0.65 | 29.52 / 29.47 |
| 第 7 层输入 | 0.75 / **0.81** | 0.41 | 29.47 / 29.24 |
| 第 12 层输入 | 0.02 / 0.05 | 0.10 | 29.01 / 28.35 |

- 中间层注入的深度错误大部分会被拉回原来的预测；只看到一个视角的 token 也能拉回。只有最后一层的扰动保留下来，这是因为后面已经没有层可以修正。
- 横向扰动的恢复率较低，但离面距离只增加约 0.6 cm（中位），主要是沿表面滑动，并不算几何错误。
- **这推翻了此前“几何门控导致误差锁死”的推测。** 模型会回到它自己的预测，不论这个预测是对是错；也就是说，错误出在模型最终收敛到的判断本身，而不是“改不动”。

### 实验 3：冻结特征的候选评分（50 个验证场景，每个模型约 1066 万个像素）

A 组指“模型误差 > 5%、可见视角数 ≥ 2、真值在候选范围内”的像素。

| 深度来源 | A 组占比 | 模型自身 | 冻结特征候选 | RGB 候选 | 直接残差 | 光度一致性 | 候选上限 | 在模型误差 < 2% 的像素上被改坏的比例（特征 / 直接残差） |
|---|---:|---:|---:|---:|---:|---:|---:|---|
| release | 30.5% | 0.137 | 0.142（+3%） | 0.150 | **0.113（−18%）** | 0.168 | 0.005 | 46% / 9% |
| ⑫ | 16.9% | 0.105 | 0.181（+73%） | 0.152 | 0.104（−0.5%） | 0.164 | 0.005 | 53% / 0.2% |
| LocusGS | 31.8% | 0.134 | 0.162（+21%） | 0.150 | **0.102（−24%）** | 0.165 | 0.006 | 62% / 12% |

表中数字为 A 组平均相对误差，括号里是相对模型自身的变化。

- 三种候选评分方式（冻结特征、RGB、光度一致性）都比模型本身更差，而且会把大量原本正确的像素改坏。
- 直接残差在零样本模型上能减少 18–24% 的误差（未达到 30% 的门槛），但在已经用激光监督微调过的 ⑫ 上几乎没有效果。这更像是学到了 ScanNet++ 的领域先验修正，而不是用上了被忽略的多视角证据。

### 事后补充分析（不在登记协议内，只作解释，不改变上面的判定）

1. **候选分辨率**（`results_posthoc_resolution.json`）：每一步 2% 的深度变化，在输入图上让投影点移动的距离，中位只有 0.49 px（取各视角中的最大值）；整个 ±30% 的范围中位只移动 14.5 px，不到两个 8 px 图像块。但即使在每步移动超过 2 px 的像素上，候选评分器仍然不如模型。所以分辨率不足不能完全解释失败。
2. **正向对照**（`results_posthoc_projection_check.json`）：把候选中心直接放在激光真值上，再用光度一致性挑选，挑中真值 ±1 步以内的比例只有 17–39%（随机为 10%），真值候选的中位排名在 31 个里的第 4–10 位。这说明投影几何是正确的，但在这种基线和分辨率下，原始像素层面的多视角证据本身就很弱。
3. **评分器拟合不足**：训练集上的交叉熵是 2.98–3.16，而均匀猜测是 3.43，说明评分器连训练集都没拟合好。因此，实验 3 的失败不能证明“特征里没有证据”，只能说明“这一类轻量探针没有找到证据”。
4. **深度分散能预测误差**（`results_posthoc_spread_vs_error.json`）：在平面内部像素上，模型自身的中心深度分散与共同偏差的 Spearman 相关为 0.45–0.66。分散最大的 1/5 像素，偏差中位是分散最小的 1/5 的 6–15 倍（release：41 cm 对 2.7 cm；⑫：7.9 cm 对 1.3 cm）。也就是说，厚度在很大程度上像是模型隐含的“不确定度”。需要注意，这里的偏差和分散都以米为单位，远处像素两者都偏大，相关性有一部分可能来自距离；还需要用相对单位复核。

### 对研究方向的含义

- **不建议**把“候选—证据—纠错”作为主线：既没有找到被忽略的证据，LocusGS 的更新机制也并非改不动。
- **支持度上升**的方向是“厚度代表未解决的不确定性”：在这个基线和分辨率下，深度本身病态（证据弱）；而模型的分散又与误差高度相关。下一步应当检验：显式的不确定性表示，能否比“用厚度隐式表达”更准、更薄，同时保持画质。
- 同表面冲突在 LocusGS 上真实存在，可以作为一个次要动机，但对 release 和 ⑫ 来说，主要误差是整体偏差。
- 激光监督微调（⑫）同时降低了偏差和冲突，说明“训练期特权几何”这条路是有效的。
